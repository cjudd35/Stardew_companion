# Stardew_companion
Mobile app for tracking progress in Stardew Valley.

# Goals
Launch features:

	Item database
    Name, Location, season
  
	community center information
    Item, quantity

Future features
  
	Interactive community board
    If acquired, if donated, link to item or item info, reward info
  
	Item database improvements
    graphic, gift information, sale cost, acquire hints
  
	Gift manager
    loved/liked gifts, birthdays, link to item database
  
	Crop calendar
    when to plant/harvest hints, cost/price calculator
  
	Customize community center for re-mix bundles
    change items in bundles, change bundles completely, include movie theater
